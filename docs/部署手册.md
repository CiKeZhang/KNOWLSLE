# 部署手册

## 一、环境要求

| 组件 | 最低版本 | 说明 |
|------|---------|------|
| Docker | 20.10+ | 容器化部署 |
| Docker Compose | 2.0+ | 服务编排 |
| 服务器配置 | 4核 8G 100G | 支持 500 学生 + 50 导师 |
| 操作系统 | CentOS 7+ / Ubuntu 20+ | Linux 服务器 |
| 网络端口 | 8080(前端)、3000(API)、3306(MySQL)、6379(Redis) | 校园网内开放 |

## 二、一键部署流程

### 2.1 克隆代码到学院服务器

```bash
git clone <仓库地址> /opt/kygl
cd /opt/kygl
```

### 2.2 配置环境变量

```bash
cp .env.example .env
```

编辑 `.env` 文件,**必须修改**以下项为随机强密码:

```env
MYSQL_ROOT_PASSWORD=<修改为强密码>
MYSQL_PASSWORD=<修改为强密码>
REDIS_PASSWORD=<修改为强密码>
JWT_SECRET=<修改为32字节以上随机字符串>
ENCRYPTION_KEY=<修改为32字节以上随机字符串>
```

生成随机密钥:
```bash
openssl rand -hex 32  # 用于 JWT_SECRET
openssl rand -hex 32  # 用于 ENCRYPTION_KEY
```

### 2.3 启动服务

```bash
docker compose up -d
```

首次启动会自动:
1. 拉取 MySQL 8.0、Redis 7、Node 18 镜像
2. 构建前端(Nginx)与后端(NestJS)镜像
3. 执行数据库迁移 `prisma migrate deploy`
4. 初始化数据库表结构与索引

### 2.4 验证部署

```bash
# 检查服务状态
docker compose ps

# 访问前端
http://<服务器IP>:8080

# 访问 API 文档
http://<服务器IP>:3000/api/docs

# 默认管理员账号(首次登录后请立即修改密码)
用户名: admin
密码: admin@2026
```

## 三、对接学院现有系统

### 3.1 统一身份认证(CAS/SSO)

系统预留 JWT 认证接口,支持对接学院 CAS 单点登录:
1. 在 `.env` 中配置 `CAS_BASE_URL`
2. 在 `backend/src/auth/strategies/cas.strategy.ts` 中实现 CAS 回调
3. 学生使用学号一键登录,无需额外注册

### 3.2 企业微信通知

在系统管理 → 系统配置 → 通知通道中填写:
- 企业微信 CorpID
- 应用 AgentID
- 应用 Secret

配置后,打卡提醒/逾期预警将自动通过企业微信推送。

### 3.3 教务系统对接

预留 `/api/admin/import` 批量导入接口,支持从教务系统导出 Excel 后一键导入学生/导师账号。

## 四、数据备份与恢复

### 4.1 自动备份

系统每日凌晨 2:00 自动执行 mysqldump,备份文件保存在 `/app/backups`,保留最近 30 天。

### 4.2 手动备份

系统管理 → 数据备份 → 立即备份

### 4.3 数据恢复

系统管理 → 数据备份 → 选择备份文件 → 恢复

**注意:恢复操作会覆盖当前数据,请先备份当前数据。**

### 4.4 命令行备份

```bash
# 进入 MySQL 容器手动备份
docker exec kygl_mysql mysqldump -ukygl -p kygl | gzip > backup.sql.gz

# 恢复
gunzip < backup.sql.gz | docker exec -i kygl_mysql mysql -ukygl -p kygl
```

## 五、反向代理(可选)

如需通过 80/443 端口访问,配置 Nginx 反向代理:

```nginx
server {
    listen 80;
    server_name kygl.your-college.edu.cn;

    location / {
        proxy_pass http://localhost:8080;
    }

    location /api {
        proxy_pass http://localhost:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 六、常见问题

### Q: 启动后访问 8080 端口显示 502
A: 检查后端容器是否启动成功 `docker logs kygl_backend`,确认 MySQL 健康检查通过。

### Q: 数据库迁移失败
A: `docker exec -it kygl_backend npx prisma migrate deploy` 手动执行迁移,查看错误日志。

### Q: AI 推荐只返回规则结果,无大模型解释
A: 在 `.env` 中配置 `LLM_API_KEY`,支持智谱 GLM / 通义 / DeepSeek / OpenAI 兼容接口。

### Q: 企业微信推送失败
A: 检查企业微信应用配置,确认手机号已导入企业微信通讯录。
