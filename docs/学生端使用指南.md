# 学生端使用指南(含周度打卡专项操作说明)

## 一、登录

1. 浏览器访问系统地址(辅导员告知)
2. 输入学号与初始密码(首次登录后请修改)
3. 支持电脑端网页与手机端浏览器自适应访问

## 二、本周打卡(核心功能)

### 2.1 打卡周期

- 每周一 00:00 至周日 23:59 为一个打卡周期

- 每周至少完成 1 次有效打卡

- 周五系统自动推送打卡提醒

- 周日晚间推送逾期预警

### 2.2 打卡操作(3 步完成)

**第一步:选择当前流程节点**

从 9 个标准化进度标签中选择你当前所处阶段:

- 未开始备考 / 择校阶段 / 基础复习 / 强化刷题 / 冲刺阶段 / 初试结束待成绩 / 初试通过备战复试 / 调剂中 / 考研结束

**第二步:勾选本周核心完成事项**

勾选本周已完成的事项(如:完成公共课知识点学习、完成真题练习等),支持添加自定义事项。

**第三步:填写本周备考困难**

如实填写本周遇到的困难(必填),辅导员/导师会据此提供针对性帮扶。

### 2.3 选填项(建议填写)

- 本周学习总时长(小时)

- 公共课/专业课进度百分比(滑块)

- 模考分数(政治/英语/数学/专业课)

- 目标院校/专业是否调整

### 2.4 补卡申请

如本周逾期未打卡:

1. 在补卡有效期内(默认 3 天)点击"补卡申请"
2. 填写未按时打卡的原因
3. 提交后等待辅导员审批
4. 审批通过后视为补卡成功

### 2.5 网络异常处理

如提交打卡时网络异常:

- 系统自动将打卡数据本地缓存

- 网络恢复后自动同步提交

- 不会丢失打卡数据

## 三、个人考研档案

- 查看完整备考时间线(阶段切换 + 打卡记录)

- 更新目标院校/专业、各科进度、模考成绩、初试分数

- 查看考研关键节点提醒(预报名、正式报名、现场确认、初试等)

## 四、AI 择校助手

1. 填写本科专业、绩点、专业排名、意向地区、院校层次偏好等
2. 点击"生成择校方案"
3. 查看分档推荐:冲刺 / 稳妥 / 保底(每档至少 3 个选项)
4. 每条推荐包含:匹配度、上岸概率、难度、推荐理由、风险点
5. 可调整参数重新生成,保存多版历史推荐记录

## 五、备考资源

- 按专业、分阶段浏览备考资料(公共课、专业课真题、经验贴、参考书目)

- 点击资源查看详情,支持下载

## 六、备考计划

- 系统根据当前阶段自动生成本周/本月学习任务清单

- 可手动调整任务(新增/编辑/删除)

- 勾选完成任务,查看完成率

- 支持基于当前阶段重新生成计划

## 七、学业帮扶

1. 点击"学业帮扶" → 提交帮扶申请
2. 选择帮扶类型:择校困惑/单科瓶颈/心态问题/复试指导
3. 填写帮扶内容(可选择对接辅导员/专业导师)
4. 打卡时反馈的困难可一键转化为帮扶申请
5. 查看导师回复与对接安排

## 八、我的消息

- 查看打卡提醒、逾期预警、关键节点通知、帮扶回复等站内消息

- 支持企业微信/短信推送(需学院配置)
