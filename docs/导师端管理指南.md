# 导师端管理指南

## 一、角色说明

| 角色 | 权限范围 |
|------|---------|
| 辅导员 | 查看所负责班级学生、处理帮扶/补卡申请、记录帮扶 |
| 专业导师 | 查看本专业学生、提供专业课指导、AI 推荐校准 |
| 教学管理员 | 全院数据总览、统计报表导出、资源库管理 |

> 严格权限隔离:仅可查看管辖范围内的学生数据。

## 二、考研进度看板

### 2.1 数据总览

进入"考研看板",查看:
- 考研报名人数、各进度阶段人数占比
- 目标院校层次分布(985/211/双一流/双非)
- 初试通过率、上岸率
- **本周打卡率、累计打卡率、逾期未打卡人数**

### 2.2 可视化图表

- 进度分布饼图
- 阶段变化趋势图
- 院校分布柱状图
- 周度打卡率趋势图

### 2.3 多条件筛选

按班级、专业、备考阶段、目标地区、初试分数段、打卡状态快速筛选学生。

## 三、周度打卡统计

1. 进入"打卡统计"
2. 查看管辖范围内学生的本周打卡率
3. 查看连续打卡人数、逾期未打卡人数
4. 支持按班级/专业导出周度打卡统计表(Excel)

## 四、异常预警与重点关注

### 4.1 自动预警规则

进入"异常预警"查看自动生成的预警:
- **打卡异常**:当周逾期未打卡、连续 2 周未打卡、连续 3 周进度无更新
- **进度异常**:备考进度明显滞后、初试成绩未达国家线、调剂无进展
- **状态异常**:连续 15 天未登录系统

### 4.2 手动标记

点击学生 → "重点关注" → 添加备注说明,置顶展示。

### 4.3 一键批量通知

选择未打卡/预警学生 → "批量发送提醒" → 自定义通知内容 → 站内信 + 企业微信 + 短信多通道触达。

## 五、学生详情

点击学生姓名进入详情页:
- **基础信息**:姓名、学号、班级、专业、当前阶段、目标院校
- **进度详情**:公共课/专业课进度、初试总分、复试进度
- **打卡轨迹**:所有打卡记录,每次上报的流程阶段与困难描述
- **AI 择校方案**:查看推荐结果,可对每条推荐进行"标注修正"(人工校准)
- **帮扶记录**:历史帮扶申请与对接情况

## 六、帮扶管理

1. 进入"帮扶管理"
2. 查看待处理帮扶申请
3. 点击"接受对接"分配给自己
4. 记录帮扶内容、时间、效果
5. 标记为"已解决"关闭帮扶工单

## 七、补卡审批

1. 进入"补卡审批"
2. 查看学生提交的补卡申请(含原因)
3. 审批通过 → 该周打卡状态标记为"逾期补"
4. 审批驳回 → 填写驳回理由

## 八、报表导出

1. 进入"报表导出"
2. 选择范围(全院/院系/专业/班级)和时间(学期/月份)
3. 一键生成学院考研工作报表(参与率、阶段分布、打卡完成率、上岸情况)
4. 导出 Excel(周度打卡统计表)或 PDF(进度汇总表)
