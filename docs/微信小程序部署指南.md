# 微信小程序部署指南(学生端)

## 一、前期准备

### 1.1 注册微信小程序

1. 访问 <https://mp.weixin.qq.com> 注册小程序账号
2. 完成主体认证(学院/学校资质)
3. 在 **开发管理 → 开发设置** 中获取:

   - AppID(填入 `miniprogram/project.config.json` 的 `appid` 字段)

   - AppSecret(填入后端 `.env` 的 `WECHAT_SECRET`)

### 1.2 配置后端域名

在 **开发管理 → 开发设置 → 服务器域名** 中配置:

- request 合法域名:`https://你的后端API域名`(必须 HTTPS)

## 二、后端配置

在后端 `.env` 中添加:

```env
WECHAT_APPID="wx_你的小程序AppID"
WECHAT_SECRET="你的小程序AppSecret"
```

重启后端服务使配置生效。

## 三、小程序配置

### 3.1 修改 API 地址

编辑 `miniprogram/config.js`:

```js
module.exports = {
  apiBase: 'https://你的后端API域名/api',
};
```

### 3.2 修改 AppID

编辑 `miniprogram/project.config.json`:

```json
{
  "appid": "wx_你的小程序AppID",
  ...
}
```

## 四、运行与预览

### 4.1 安装微信开发者工具

下载:<https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>

### 4.2 导入项目

1. 打开微信开发者工具
2. 选择 **导入项目**
3. 项目目录选择 `/Users/macbookpro/Desktop/empty-window/经管考研/miniprogram`
4. 填入 AppID
5. 点击导入

### 4.3 本地开发调试

在开发者工具中:

1. 点击 **详情 → 本地设置**
2. 勾选 **不校验合法域名、web-view(业务域名)、TLS 版本以及 HTTPS 证书**
3. 修改 `config.js` 的 apiBase 为 `http://localhost:3000/api`(后端本地运行时)
4. 点击 **编译** 预览效果

## 五、登录流程说明

学生首次使用小程序:

```
1. 点击「微信一键登录」
   ↓ wx.login() 获取 code
   ↓ 后端 POST /auth/wechat/login 换 openid

2. 点击「授权手机号」(可选)
   ↓ getPhoneNumber 获取 code
   ↓ 后端 POST /auth/wechat/phone 换手机号

3. 填写「真实姓名 + 学号」
   ↓ 后端 POST /auth/wechat/complete
   ↓ username 自动生成为「姓名+学号」
   ↓ 创建学生账号 + 签发 JWT
   ↓ 进入首页
```

后续打开小程序:

- token 有效期 7 天,期间无需重复登录

- token 过期自动跳转登录页

## 六、上线发布

1. 在开发者工具中点击 **上传**
2. 填写版本号和项目备注
3. 在 mp.weixin.qq.com 后台 **版本管理** 中提交审核
4. 审核通过后点击 **发布**

## 七、导师/管理员端

导师和管理员仍通过 **Web 端**(浏览器)登录管理,账号由系统管理员创建:

- 访问地址:<http://后端域名:8080>

- 角色:辅导员、专业导师、教学管理员、系统管理员

## 八、注意事项

1. **数据安全**:学生目标院校等 PII 字段已 AES-256-GCM 加密存储
2. **权限隔离**:学生仅能查看和编辑个人数据
3. **消息推送**:打卡提醒、逾期预警通过站内信+企业微信+短信多通道推送
4. **离线缓存**:打卡提交失败时自动缓存,网络恢复后自动同步
