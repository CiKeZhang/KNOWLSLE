# 管理员运维手册

## 一、账号管理

### 1.1 单个账号管理

系统管理 → 账号管理:
- 新增用户(学生/辅导员/专业导师/教学管理员)
- 编辑用户信息(角色、院系、专业、班级)
- 重置密码(重置为 `用户名@2026`)
- 停用账号

### 1.2 批量导入

系统管理 → 批量导入:
1. 下载 Excel 模板
2. 按模板填写学生/导师信息(姓名、学号/工号、角色、院系、专业、班级)
3. 上传 Excel,预览数据
4. 确认导入,系统自动创建账号

### 1.3 对接统一身份认证

预留 CAS/SSO 接口,配置后学生可通过学号一键登录,无需单独创建账号。

## 二、打卡规则配置

系统管理 → 打卡规则:

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 打卡周期 | 自然周 / 双周 | 自然周 |
| 每日起止时间 | HH:mm | 00:00 - 23:59 |
| 周五提醒时间 | 打卡提醒推送 | 18:00 |
| 周日预警时间 | 逾期预警推送 | 20:00 |
| 必填项 | 流程节点/完成事项/困难 | 全部必填 |
| 补卡功能 | 开启/关闭 | 开启 |
| 补卡有效期 | 天数 | 3 天 |
| 补卡审批角色 | 辅导员/专业导师/教学管理员 | 辅导员 |

## 三、资源库管理

系统管理 → 资源库:
- 上传资源(公共课资料、专业课真题、经验贴、参考书目)
- 审核待审资源(通过/驳回)
- 下架已上线资源
- 按类型、阶段、专业分类

## 四、院校数据库维护

系统管理 → 院校数据库:
- 新增院校(名称、代码、层次 985/211/双一流/双非、地区)
- 设置优先推荐权重(本院对口升学方向)
- 管理招生专业(专业名称、近 3 年报录比、复试线、招生人数、考试科目)
- 数据按年度更新

## 五、系统配置

### 5.1 预警规则

系统管理 → 系统配置 → 预警规则:
- 当周逾期未打卡预警(开/关)
- 连续 N 周未打卡预警(默认 2)
- 连续 N 周进度无更新预警(默认 3)
- 进度滞后于均值 N% 预警(默认 20)
- 连续 N 天未登录预警(默认 15)

### 5.2 关键节点提醒

系统管理 → 系统配置 → 考研关键节点:
- 预报名、正式报名、现场确认、初试、成绩公布、国家线、复试、调剂
- 配置每个节点的提醒时间与描述
- 启用/停用

### 5.3 通知通道

系统管理 → 系统配置 → 通知通道:
- 站内消息(默认开启)
- 企业微信(配置 CorpID/AgentID/Secret)
- 短信(配置阿里云/腾讯云 AccessKey)

## 六、操作日志

系统管理 → 操作日志:
- 全量操作留痕(登录、打卡、补卡、帮扶、配置变更等)
- 按用户、操作类型、时间范围筛选
- 鼠标悬停查看操作详情(JSON)
- 可追溯、可审计

## 七、数据备份

系统管理 → 数据备份:
- 查看备份列表(文件名、大小、时间)
- 立即备份(手动触发 mysqldump)
- 一键恢复(从指定备份文件恢复)
- 自动备份:每日凌晨 2:00,保留 30 天

## 八、运维监控

### 8.1 查看服务状态

```bash
docker compose ps
docker compose logs -f --tail=100 backend
```

### 8.2 性能指标

- 并发支持:500 学生 + 50 导师同时在线
- 核心功能响应时间:≤ 2 秒
- 数据库连接池:20 连接(可调)
- Redis 缓存:限流与缓存
- 限流:200 请求/分钟/用户

### 8.3 常见运维操作

```bash
# 重启后端
docker compose restart backend

# 查看数据库
docker exec -it kygl_mysql mysql -ukygl -p kygl

# 手动备份
docker exec kygl_backend node -e "require('./dist/common/services/backup.service').createBackup()"

# 查看磁盘空间
docker system df
```

## 九、安全合规

- 三级权限隔离:学生 / 导师 / 管理员
- 敏感数据加密:AES-256-GCM(目标院校、专业等 PII 字段)
- 全操作日志留存:可追溯、可审计
- JWT 认证:12 小时有效期
- HTTPS:建议配置 SSL 证书
- Helmet 安全头 + 限流防护
